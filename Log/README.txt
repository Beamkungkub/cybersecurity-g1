ข้อตกลงของชุดข้อมูลนี้
----------------------
1. ชื่อผู้ใช้ถูกแทนด้วย user1, user2, ... (คงความสม่ำเสมอทั้งชุด ถ้าค่าเดิมเดียวกันจะได้ค่าใหม่เดียวกัน)
2. ฟิลด์ cs(Cookie) ถูกทำให้ว่างเป็น "-" ทุก record
3. ชื่อเส้นทางของแอปถูกเปลี่ยน: webname (ระบบหลัก), AppName (บริการเอกสาร)
4. ชื่อโฮสต์เป็น example.ac.th และชื่อเซิร์ฟเวอร์เป็น WEB01
5. หมายเลข IP ภายในคงไว้ตามจริง เพื่อให้วิเคราะห์โครงข่ายได้

ข้อปฏิบัติ
----------
* ใช้เพื่อการเรียนในรายวิชานี้เท่านั้น
* ห้ามพยายามระบุตัวตนบุคคลหรือหน่วยงานจากข้อมูลนี้
* ห้ามเผยแพร่หรืออัปโหลดขึ้นบริการภายนอก
