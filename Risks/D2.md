# D2 – Payroll and Personnel Application Functions Reachable from External Source Addresses Resulting in Expanded Exposure of Personal Data

**Series:** D
**Likelihood × Impact:** L 4 × I 4 = R 16 🟠 High
**Evidence Confidence:** Medium
**Affected Asset / System:** ORG1-APP1 – โมดูล MIS/Staff (RepSlip, StaffSalary, StaffInfo, Web025_1, StaffAttRequestData)
**Target / Environment:** -
**Analysis Date:** 2026-11-26
**Log Range:** 2025-11-19 00:00:00 – 2025-11-28 23:50:00
**Evidence Sources:** `u_ex251119.log` – `u_ex251128.log`, `result_v2.txt`, `result_v3.txt`, `README.txt`

## Risk Statement

เนื่องจากหน้าเงินเดือน ใบจ่ายเงินเดือน และข้อมูลบุคลากรถูกเรียกใช้จากหมายเลข IP ภายนอกเครือข่ายภายใน (ไม่ใช่ช่วง private) อย่างต่อเนื่อง โดยไม่ปรากฏหลักฐานของการจำกัดเครือข่ายหรือการยืนยันตัวตนเพิ่มเติม อาจทำให้บัญชีผู้ใช้ที่ถูกขโมยหรือถูกใช้ผิดวัตถุประสงค์เข้าถึงข้อมูลบุคลากรจากอินเทอร์เน็ตได้ ส่งผลให้ความลับของข้อมูลส่วนบุคคลและข้อมูลเงินเดือนของบุคลากรมีความเสี่ยงสูงขึ้น

## เหตุผลการให้คะแนน

- **Likelihood 4:** พบการเข้าถึงจากภายนอกต่อเนื่องหลายวันและหลายผู้ใช้ (RepSlip ภายนอก 27 request จาก 13 IP) แต่ผู้ใช้ส่วนใหญ่ล็อกอินแล้วและไม่พบรูปแบบโจมตี จึงไม่ให้ 5
- **Impact 4:** กระทบหลาย workflow ของงานเงินเดือนและข้อมูลบุคลากร เป็นข้อมูลส่วนบุคคลที่อ่อนไหวต่อ PDPA
- **Risk Level:** High (16) – ผลกระทบสูงและพฤติกรรมต่อเนื่อง แต่หลักฐานยังไม่แสดงการเข้าถึงโดยไม่ได้รับอนุญาต

## หมวดหมู่ความเสี่ยง

- **Primary Category:** Trust Boundary & Access Control Failure
  - หน้าข้อมูลอ่อนไหวเข้าถึงได้จากภายนอก trust boundary ภายใน
- **Secondary Categories:**
  - **Identity & Authentication Risks:** ความเสี่ยงจากบัญชีที่ถูกใช้ผิดวัตถุประสงค์เมื่อไม่มีหลักฐานการยืนยันตัวตนเพิ่มเติม
  - **Data Exposure/Privacy Risk:** ข้อมูลเงินเดือนและข้อมูลบุคลากร

## หลักฐาน

### E-01 – การเรียกหน้าเงินเดือน/บุคลากรจาก IP ภายนอก

**Source:** `result_v3.txt` หัวข้อ C และ D (สรุปจาก `u_ex251119.log` – `u_ex251128.log`)
**Timestamp:** 2025-11-19 – 2025-11-28

**Observed Facts:**
- RepSlip: ภายนอก 27 request (13 IP, 11 ผู้ใช้) status 200 จำนวน 26 และ 500 จำนวน 1
- StaffSalary: ภายนอก 21 request (18 IP, 14 ผู้ใช้) status 200 ทั้งหมด
- Web025_1: ภายนอก 21 request (6 IP, 6 ผู้ใช้) status 200 จำนวน 20 และ 302 จำนวน 1
- StaffInfo: ภายนอก 4 request (4 IP, 4 ผู้ใช้) status 200 ทั้งหมด
- StaffAttRequestData: ภายนอก 30 request (4 IP, 4 ผู้ใช้) status 200 ทั้งหมด
- RepSlip ถูกเรียกจากภายนอกในเก้าวันจากสิบวัน

**Security Interpretations:**
- สอดคล้องกับผู้ใช้ที่ทำงานนอกเครือข่ายหรือใช้ผ่านอินเทอร์เน็ต
- "ภายนอก" ในที่นี้หมายถึง IP ที่ไม่อยู่ในช่วง private เท่านั้น อาจเป็นทางออกของ VPN หรือ NAT ขององค์กรเอง ยืนยันไม่ได้

### E-02 – ภาพรวมการจราจรภายนอกและการเข้ารหัส

**Source:** `u_ex251119.log` – `u_ex251128.log` (ฟิลด์ `c-ip`, `s-port`, `cs-username`)
**Timestamp:** 2025-11-19 – 2025-11-28

**Observed Facts:**
- มี IP ภายนอก 123 ตัว (IP ภายใน 142 ตัว)
- request ภายนอกที่ไม่ใช่ไฟล์ static มี 930 ครั้ง โดย 559 ครั้งมี username (23 ผู้ใช้)
- ผู้ใช้ 12 ราย จากทั้งหมด 121 ราย พบทั้งจาก IP ภายในและภายนอก
- พอร์ต 443 มี 19,310 request ส่วนพอร์ต 80 มี 1,509 request ซึ่งเป็น loopback และ IP ภายในเท่านั้น (ไม่มี IP ภายนอกบนพอร์ต 80)

**Security Interpretations:**
- การจราจรภายนอกใช้ HTTPS ทั้งหมดตามที่ log แสดง ซึ่งเป็นผลดีต่อการรั่วระหว่างทาง
- ไม่พบหลักฐานของการจำกัดต้นทาง (เช่น IP allowlist) บนหน้าข้อมูลอ่อนไหว แต่ log ไม่ใช่แหล่งที่จะยืนยัน

### E-03 – คำขอหน้าอ่อนไหวที่ไม่มี username

**Source:** `u_ex251119.log` – `u_ex251128.log` (ฟิลด์ `cs-username`, `sc-bytes`, `sc-status`)
**Timestamp:** 2025-11-19 – 2025-11-27

**Observed Facts:**
- หน้าอ่อนไหว (.aspx) มี 673 request โดย 14 request (ประมาณ 2.1%) ไม่มี username (`-`)
- ในนั้นมี 5 request จากภายนอก: StaffSalary 3 ครั้ง (status 200 ขนาดตอบกลับประมาณ 9 KB ซึ่งเล็กกว่าค่ากลางของหน้าที่มี username ประมาณ 70 KB), StaffAttRequestData 1 ครั้ง (status 200 ขนาด 33 KB) และ RepSlip 1 ครั้ง (status 500)

**Security Interpretations:**
- อาจเป็นช่องว่างของการบันทึก username (เช่น คำขอแรกของ session หรือ request แบบ postback) มากกว่าการเข้าถึงโดยไม่ยืนยันตัวตน
- ยังสรุปไม่ได้ ควรตรวจกับเจ้าของระบบเพราะ response body ไม่ถูกบันทึก

## การวิเคราะห์ช่องโหว่และความเสี่ยง

1. **External Reachability of Payroll/Personnel Functions:**
   - **Evidence:** E-01, E-02
   - **Analysis:** หน้าข้อมูลอ่อนไหวถูกเรียกจาก IP ภายนอกหลายตัวต่อเนื่องหลายวัน
   - **Potential Impact:** หากบัญชีถูกขโมย ผู้โจมตีเข้าถึงข้อมูลเงินเดือนผ่านอินเทอร์เน็ตได้โดยตรง
   - **Limitation:** ไม่ทราบว่ามี VPN, MFA หรือการจำกัดต้นทางอยู่หรือไม่ และ IP ภายนอกอาจเป็นของผู้ใช้ที่ได้รับอนุญาตทั้งหมด

2. **Identity Attribution Gaps on Sensitive Pages:**
   - **Evidence:** E-03
   - **Analysis:** มีคำขอจำนวนเล็กน้อยที่ไม่มี username ปรากฏใน log
   - **Potential Impact:** ตรวจสอบย้อนหลังว่าใครเรียกข้อมูลได้ไม่ครบ
   - **Limitation:** ไม่ทราบสาเหตุและขนาดตอบกลับของบางรายการชวนให้สงสัยแต่ไม่ยืนยัน

## ข้อแนะนำ

### Immediate / Short-term (Quick Win)

1. **จำกัดการเข้าถึงโมดูลเงินเดือน/บุคลากรจากภายนอกผ่าน VPN หรือ IP allowlist**
   - **Priority:** High
   - **Owner:** Network / Infrastructure Team
   - **Estimated Effort:** Medium
   - **Verification:** ตรวจ log หลังบังคับว่าไม่พบ IP ภายนอกที่ไม่ผ่าน VPN เรียก `/MIS/Staff/*`
2. **ตั้งการแจ้งเตือนเมื่อมีการเข้าถึงหน้าเงินเดือนจาก IP ที่ไม่เคยพบ**
   - **Priority:** Medium
   - **Owner:** Security / SOC
   - **Estimated Effort:** Medium
   - **Verification:** ทดสอบด้วย request จาก IP ทดสอบแล้วต้องเกิด alert

### Long-term / Architectural Fix

1. **บังคับ MFA และตั้งนโยบาย session timeout สำหรับโมดูลเงินเดือน**
   - **Priority:** High
   - **Owner:** Application Development + Security
   - **Estimated Effort:** High
   - **Verification:** ทดสอบการล็อกอินว่าต้องผ่าน MFA และ session หมดอายุตามนโยบาย
2. **บันทึก username ให้ครบทุก request ที่เข้าถึงหน้าอ่อนไหว**
   - **Priority:** Medium
   - **Owner:** Application Development
   - **Estimated Effort:** Low
   - **Verification:** ตรวจ log ว่า request ของหน้า `/MIS/Staff/*` ทุกรายการมี username
